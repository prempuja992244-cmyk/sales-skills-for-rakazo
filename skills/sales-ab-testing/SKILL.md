# Outreach A/B testing

## Set up a test
1. **One change only** per test (subject OR opening line OR CTA OR offer).
2. **Hypothesis**: "A pain-led opener will get more replies than a proof-led opener from operations heads."
3. **Metric**: positive reply rate (best), reply rate, or meetings booked. Opens are unreliable; don't use them as the main metric.
4. **Split** the same segment randomly 50/50; send in the same time window.
5. **Sample size**: aim for at least ~100–200 sends per variant before judging; with smaller lists, treat results as directional.

## Track
Variant | Sent | Replies | Positive replies | Meetings | Rate. Tag each sent message with its variant in the CRM/sheet.

## Read results
- Declare a winner only if the difference is large and the sample is meaningful; otherwise call it "no clear winner" and keep testing.
- Check for confounders (different send days, one variant hit more big companies).
- Roll the winner into the sequence; start the next test.

## Test ideas (in priority order)
1. Targeting/segment (biggest effect)
2. Offer / call to action ("15-min call" vs "send a 2-min video")
3. First line / hook type
4. Subject line
5. Send day/time and channel order

## Output
Test plan, tracking table, and a plain-language result summary with the recommended next test.
